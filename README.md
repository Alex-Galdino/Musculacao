# Musculação — Treino ABC

Checklist de musculação (treinos A/B/C) para usar no celular durante o treino:
marcar séries, anotar carga/reps/RIR, cronômetro de descanso de 2 min com bipe,
fases de retorno (Sem 1–2, 3–4, 5–6, 7+) e histórico com volume em kg.

Os dados ficam salvos no navegador (localStorage). Use **Exportar** na página
para guardar um backup em JSON e **Importar** para restaurá-lo.

Arquivo único: `index.html`, sem dependências além da fonte Barlow (Google Fonts).

Página publicada em: https://alex-galdino.github.io/Musculacao/
